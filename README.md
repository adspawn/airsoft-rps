# エアソフトガン サイクル測定

発射音を録音し、波形のピーク間隔から秒間発射数（RPS）/ RPM を計算するウェブアプリです。
音声はブラウザ内だけで処理され、外部には送信されません。

## 使い方
1. 「録音開始」→ フルオートで1〜3秒撃つ →「停止」（または録音済みの音声/動画ファイルを開く）
2. 波形上の赤線が検出した発射。誤検出があれば「しきい値」「最小間隔」を調整
3. 波形をドラッグすると解析範囲を絞れます（トリガー音・雑音の除外）

## GitHub Pages
Settings → Pages → Source: `Deploy from a branch` / Branch: `main` / `(root)` で公開されます。
マイク録音には HTTPS が必要ですが、GitHub Pages は HTTPS なのでそのまま動作します。
